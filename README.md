A hand-drawn newspaper front page summing up Thursday 26 November 2026:
44 real stories, 15 drawn scenes, a world map with 32 numbered pins, and a
numbers bar — all drawn in code with Python PIL from the day's reporting.

Headlines: the Houthi strike on Saudi Arabia's Ras Tanura refinery and
Riyadh (Brent over $94), Thanksgiving Day in the US, and the first
Pakistani astronaut reaching China's Tiangong station aboard Shenzhou-24.
Around them: Wall Street's wild intraday comeback, US tariffs of up to 15%
on Taiwan, the Fed's Beige Book, a plane crash off Mississippi, a fire in
Cairo, North Korea expelling Switzerland's envoy, Gukesh vs Sindarov tied
1–1 in the World Chess Championship, NATO's eastern-flank air watch, a
record migrant arrival in the Canary Islands, and 30 more stories in brief.

`main.ts` (Node 22, standard library only) copies the held `entry.png` to
the output directory — deterministic, no network, both runs identical.
